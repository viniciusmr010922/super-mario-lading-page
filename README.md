# 🍄 Super Mario - Landing Page

Uma landing page temática e interativa do universo Super Mario, desenvolvida para praticar conceitos de HTML, CSS e JavaScript.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do projeto.
- **CSS3**: Estilização, layout responsivo e animações.
- **JavaScript**: Interatividade e manipulação do DOM.

---

## 📌 Funcionalidades

- Design temático inspirado no universo do Super Mario.
- Layout responsivo adaptado para diferentes tamanhos de tela.
- Elementos interativos via JavaScript (modais, vídeos ou botões).
